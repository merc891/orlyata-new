# Контракт CMS

Этот документ фиксирует schema первого backend-цикла. Все сущности, права и поля принадлежат must-use-плагину `orlyata-core`; тема получает только подготовленные данные.

## Сущности

| Тип | Назначение | Публичная страница |
| --- | --- | --- |
| `news` | Новости, объявления и достижения-новости | да, `/novosti/{slug}/` |
| `teacher` | Педагог и его биография | да, `/o-kapelle/{slug}/`; архива педагогов нет |
| `choir_achievement` | Строка таблицы достижений капеллы | нет |
| `score` | Нотный файл | нет |
| `photo_album` | Альбом с набором фотографий и обложкой | да, `/mediagalereya/foto/{slug}/` |
| `video` | Внешнее видео | да, `/mediagalereya/video/{slug}/` |

Заявка `application` не создаётся этим этапом: её обработка, права, retention и SMTP реализуются единым защищённым циклом этапа 7.

## Закрытые словари

- `orlyata_news_category`: `news`, `announcement`, `achievement`.
- `orlyata_media_category`: `performance` («Выступления»), `rehearsal` («Занятия»), `leisure` («Отдых»), `other` («Разное»).
- `orlyata_score_choir`: `preschool`, `junior`, `senior`, `youth`.

Словари засеваются кодом, не редактируются через админ-интерфейс и присваиваются записям только select-полем CMS.

## Поля

- `news`: необязательный анонс (первый абзац детали, Heading 3), gallery image attachment IDs (до 10, в редакторском порядке), текст после галереи, SEO title, SEO description, обязательная категория; заголовок, основной текст до галереи и дата используют штатные поля WordPress.
- `teacher`: отображаемое имя, ФИО, должность, цитата, звание, достижения строками «год | название», порядок, фотографии.
- `choir_achievement`: год, результат, хор, событие, порядок.
- `score`: автор, PDF attachment ID, хор.
- `photo_album`: image attachment IDs и cover attachment ID. Обложка сохраняется только если входит в набор; иначе публичный слой получает первую доступную фотографию.
- `video`: нормализованный HTTPS URL, описание, offset превью в секундах и автоматически определённый provider.

Все сохранения проходят nonce, capability check, проверку типа и sanitization. Файлы хранятся только как ID attachment; PDF и изображения проверяются по MIME. В формах «Ноты» и «Фотоальбомы» стандартная медиатека WordPress позволяет сразу выбрать существующие файлы или загрузить новые.

## Права

`content_editor` может создавать, редактировать, публиковать и удалять разрешённые сущности, загружать файлы и менять `site_settings`. Роль не получает системных возможностей, пользователей, тем, плагинов, tools, заявок или административных настроек.

`administrator` получает все capability контентных сущностей и единственную capability управления закрытыми словарями. Отдельные capability заявок появляются только на этапе 7.

## Site settings

Опция `orlyata_site_settings` содержит адрес, телефоны, email и до пяти социальных ссылок. Социальная иконка хранится как безопасный image attachment ID; произвольный SVG или HTML не принимается.

## Видео

Провайдер выбирается не вручную. Адаптеры распознают и нормализуют допустимые URL YouTube, RuTube и VK Видео. Текущий контракт возвращает provider label и capability статичного fallback; получение browser-readable 8-секундного video-preview остаётся ответственностью provider adapter на следующем публичном цикле.

## Выборки

Публичные помощники возвращают только опубликованные записи. Медиа сортируются по `post_date` (дате создания/публикации), а не `post_modified`. Поиск нот выполняется регистронезависимо по title и автору, фильтр хора применяется вместе с поиском.
